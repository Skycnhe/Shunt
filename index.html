代理方式

      
把客户端（或主路由 DHCP 下发）的网关和 DNS 指向本机即可全局透明代理
        

      

      
TUN 选项

        
协议栈
mixed：TCP 走 system、UDP 走 gVisor（推荐）

          

        
网卡名称

        
auto-redirect
用 nftables 重定向 TCP，旁路由性能更好；内核不支持时自动关闭

        
strict-route
严格路由，防止流量绕过 TUN；可能影响局域网访问，默认关闭

        
auto-route、auto-detect-interface 已开启，DNS 劫持 any:53

      
IPv6 透明代理
核心与 DNS 启用 IPv6，并代理 IPv6 流量；需客户端以本机作为 IPv6 网关

      
故障自动直连（看门狗）
核心挂掉时自动重启，仍失败则关闭透明代理保证局域网能上网

    
绕过设备（不走代理）

      
每行一个 IP、网段或 MAC（如 192.168.1.50、2408:xxxx::/64、AA:BB:CC:DD:EE:FF）。TUN 模式下按 IP / 网段生成直连规则（MAC 仅 TProxy 有效）。被绕过的设备请把 DNS 设为主路由。

      

    
设备备注

      
每行一个：IP 或 MAC = 名称。未备注的设备会依次尝试 DHCP 租约、/etc/hosts、反向解析获取名称
